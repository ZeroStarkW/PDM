# PDM MVP → PHM 专家级系统改造与升级计划

## Context

代码库 `D:\物联网设备\预测性维护\pdm_mvp`（分支 codex/pdm-mvp，有大量未提交改造）已实现成熟的 PdM MVP：MAD+CV 基线状态机（CV≤0.15 锁定/发散）、15% 死区 Sigmoid 评分（与文档公式一致）、M-of-N(5选4, HI<50) 防抖、ISO 10816 绝对门限、规则诊断引擎、告警→工单→通知闭环、HI 趋势预测、多模态插件（振动+MCSA）、Vue3+ECharts 前端、Python 模拟器（已具备 Band RMS + 希尔伯特包络 DSP）。

设计文档《PHM 全栈系统设计说明书》要求升级为专家级 PHM。**已确认的差距**：
1. **§4.1 轴承几何库**：BPFO/BPFI/BSF/FTF 解算 + 字典表 + 绑定测点（当前无）
2. **§4.3 dk/dt 动力学雪崩抑制**：η_dyn = exp(−2.5(β₁−0.10)) 乘子（当前无）
3. **§4.4 评分补全**：文档版 ISO 曲线、温升（轴承−环境）评分、BPFI 评分、HI=min×η_dyn、确定性根因定性（不平衡/不对中/外圈/内圈/雪崩）
4. **§2 数据契约 2.0.0**：`devices/{asset_id}/{point_id}/telemetry` 主题 + 新特征（crest_factor、feat_3x、feat_sub、env_bpfi、sei_index、temp_ambient、load_current、is_steady）（当前只有 pdm/v1 与 pdm/v2 契约）
5. **§2.2 原始波形快照**：三类触发（越限/定时/召唤）+ preview_waveform + 存储 + 波形谱分析 API（当前完全没有）
6. **§7 API 面**：/api/v1/assets/tree、/api/v1/bearings/models、/api/v1/telemetry/{pointId}/features、/api/v1/diagnostics/{pointId}/waveform、POST /api/v1/workorders、/ws/v1/live-stream 实时频谱流（均无或仅部分）
7. **§8 专家频谱诊断工作站**：时域示波器（框选缩放+峰峰值卡尺）、FFT 频谱（1X~6X 谐波光标族、线性/dB 切换）、希尔伯特包络谱（BPFO/BPFI/BSF 故障线+SNR 标注）三联动视图；轴承型号模糊搜索配置；告警诊断卡片+一键派单
8. **§9 DoD**：TC-01（Band RMS 抗漂移）、TC-02（包络谱捕获 140Hz 点蚀）、TC-03（MAD 剔 5 飞刺）、TC-04（dk/dt 雪崩拦截）验收测试

**范围决策**（用户未选择，按推荐默认，可在审批时否决）：保留 PostgreSQL+InfluxDB3 存储栈（对应文档 MySQL/TDengine 架构角色，不动 11 个既有迁移与数据）；波形存 PG 预览 + 本地卷归档（`WaveformStorage` 接口留 S3 扩展点，不引入 MinIO/Redis 容器）；保持 3 级资产模型（工厂→设备→测点）+ 新增树形 API；升级 Python 模拟器到协议 2.0.0。

## 实施切片（依赖序）

### 1. Java DSP 模块（新包 `com.pdm.mvp.dsp`，无外部依赖，手写 ~300 行）
- `Fft`（迭代 radix-2 实数 FFT + 汉宁窗 + 相干增益校正）
- `ButterworthBandpass`（4 阶双二阶级联直接 II 型）
- `HilbertEnvelope`（FFT 解析信号 → 包络 → 包络谱）
- `BandRms`（频带能量积分，±3% 或 ±0.5Hz 容差，与模拟器 `extract_band_energy_rms` 语义一致）
- 单测：**TC-01**（转频 24.8~25.2Hz 随机漂移、振幅 0.5 → Band RMS 波动 ≤1.5%，同时展示单点 Peak >15% 跌落被纠正）、**TC-02**（8192Hz 采样、2kHz 载波注入 140Hz 调制微脉冲、1X 仅 0.40 → 包络谱 140Hz 检出尖峰 + 评分扣至 60 分）

### 2. Flyway 迁移 `V12__phm_upgrade.sql`（附加式）
- `pdm_bearing_library`（按文档 §5.1 #2：model_name 唯一、manufacturer、ball_count、ball_diameter、pitch_diameter、contact_angle_deg、bpfo/bpfi/bsf/ftf_factor；种子数据 6208/6308/6310/NU210/22210 等，系数用几何公式预计算，如 6208: n=9,d=12.7,D=59.5 → BPFO≈3.54, BPFI≈5.46）
- `pdm_measurement_point` 加 `bearing_model_id` FK（可空）
- `pdm_waveform_snapshot`（id, point_id, trigger_type CHECK(THRESHOLD_EXCEEDED|SCHEDULED|ON_DEMAND), sampled_at, sampling_rate, points_count, unit, storage_type, storage_ref, preview JSONB double[], health_index, created_at；索引 point+time）
- `pdm_alert_event` 加 `defect_detail` JSONB（各特征 k/得分/贡献率/η_dyn）、`raw_snapshot_url`
- `pdm_work_order` 加 `priority`（LOW..URGENT 默认 MEDIUM）、`maintenance_action`（建议措施）、`spare_parts` JSONB

### 3. 轴承几何库后端（新包 `com.pdm.mvp.bearing`）

### 4. 协议 2.0.0 遥测接入（`telemetry` 包扩展）

### 5. 健康内核升级（`analytics` 包）
- `DegradationTracker`（@Component，仿 `SpikeFilter` 的每测点内存滑动窗口 (t, k_dominant)，窗口默认 PT24H 上限 512 样本；最小二乘拟合 β₁=Δk/24h；η_dyn=exp(−2.5(β₁−0.10)) β₁>0.10 时生效）
- `HealthIndexCalculator`：ISO 曲线改为文档版（>4.5: max(10, 30−(v−4.5)·10)；2.8~4.5: 70−((v−2.8)/1.7)·25）；温升评分（actualRise/baseRise >1.8→30、>1.3→70−(ratio−1.3)·80，无环境温度时回退旧绝对温度相对分）；增 env_bpfi 相对分；**HI = clamp(min(1X,2X,BPFO,BPFI,ISO,Temp) × η_dyn)**；`HealthAssessment` 增 slopeDkDt、etaDyn、各特征贡献明细（feature/k/score）
- `DefectClassifier`：文档 §6.2 确定性根因阶梯（雪崩 penalty<0.7 → 1X 不平衡 → 2X 不对中 → BPFO 外圈 → BPFI 内圈 → ISO 击穿 → 健康），接入 `DiagnosticEvaluator` 兜底（替换"综合振动变化"泛化文案）；`AlertService` 落库 defect_detail + raw_snapshot_url（关联最新快照）

### 6. 波形快照服务与实时流（新包 `com.pdm.mvp.waveform`）
- `WaveformStorage` 接口 + `LocalVolumeWaveformStorage`（`pdm.waveform.storage-dir` 默认 ./data/waveforms；S3 实现留接口）
- `WaveformService`：MQTT/REST 两条入库路径（`POST /api/v2/waveforms` 直推备用）；存快照行 + preview + 原始数组写本地卷；触发 THRESHOLD_EXCEEDED 时与告警关联
- `WaveframeService`：快照到达后用 DSP 模块计算并缓存 时域/FFT 谱/包络谱（滤波带 1000~2500Hz 可配）
- `DiagnosticsController`：**GET /api/v1/diagnostics/{pointId}/waveform**（最新快照+谱）、**POST /api/v1/diagnostics/{pointId}/capture**（ON_DEMAND：MqttGateway 向 `devices/{asset}/{point}/cmd/capture_waveform` 发召唤指令；无边缘响应时回退最新缓存）
- `LiveStreamController`：**GET /ws/v1/live-stream?pointId=**（SseEmitter，会话认证同源 cookie；2Hz 推 `SPECTRUM_FRAME`：{timestamp, rpm, time_waveform, fft_freqs, fft_amps, envelope_amps, harmonics 1X~6X, faultLines BPFO/BPFI/BSF+幅值+SNR}；15s 心跳）；SecurityConfiguration 放行策略调整（/ws/** 需认证）

### 7. 其余 API 面

## 复用要点
- 内存滑动窗口模式：仿 `SpikeFilter`/`DeviceHealthWindow`（DegradationTracker）
- 特征码基线双写：复用 V11 `pdm_baseline_feature_state`（`BaselineService.upsertFeatureStates`）
- 插件体系：评分/基线扩展全部走 `ModalityPlugin`，MCSA 不受影响
- MQTT 出站发布：Spring Integration mqtt outbound（新增 gateway，与现有 inbound adapter 同一 client）
- 主题校验/错误吞噬模式：复用 `MqttTelemetryConsumer.dispatch`
- 前端 ECharts 命令式 initChart/主题 watch 模式：复用 `PointDetailView.vue` 模式
