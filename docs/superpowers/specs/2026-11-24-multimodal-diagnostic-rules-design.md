# 多模态设备主导因素规则设计

## 意图

让新建的 `ELECTRIC_MOTOR`、`CIRCUIT_BREAKER`、`CONTROL_VALVE` 设备也能使用系统的设备类型主导因素规则页面。当前规则计算器只在 `RotatingVibrationPlugin` 内调用；MCSA、断路器和调节阀虽有插件内置诊断，却不会读取可配置的设备类型规则。

## 目标

- 将 MCSA、断路器与调节阀规则接入实际遥测评分链路和告警诊断快照。
- 规则只覆盖主导因素、诊断依据和排查建议；健康评分、告警分档与告警门禁仍由现有模态插件决定。
- 插件报告硬限击穿时，保留插件内置因素/依据/建议，避免普通用户规则遮蔽安全硬限。
- 设备类型页面按类别显示可用指标；后端也拒绝不适用该类别的指标。
- 演示种子为三类设备幂等补齐默认因素规则。现有用户规则和启停状态不覆盖。

## 非目标

- 不更改健康评分公式、报警分档、M-of-N 防抖、MCSA 默认告警关闭状态或插件硬限阈值。
- 不声称演示阈值为现场合格标准；现有默认值需设备制造商/现场数据校准。
- 不为旋转设备改变既有规则的匹配顺序或因子行为。

## 实现方式

**已选：扩展统一可配置规则。** 在共享分析链路内，先获得模态插件诊断与评分，再用设备类型启用规则匹配遥测特征和基线。无匹配时保留插件原诊断；匹配时只替换 `DiagnosticMatch` 的因素、依据、建议、命中规则 ID 与观测值。硬限击穿优先使用插件原诊断。这样用户可统一维护规则，同时评分仍由模态机理插件负责。

诊断规则指标按设备类型分类：

| 设备类型 | 可配置指标 |
| --- | --- |
| `ELECTRIC_MOTOR` | 所有现有振动指标，以及 MCSA 边频带/载波间距（dB）、转差率（%） |
| `CIRCUIT_BREAKER` | 所有现有振动指标，以及分闸时间相对基线倍率、线圈峰值电流相对基线倍率、合闸速度相对基线倍率、触头磨损率原始值（0–1） |
| `CONTROL_VALVE` | 所有现有振动指标，以及回环死区相对基线倍率、超声泄漏 RMS、行程滞后相对基线倍率、填料摩擦力相对基线倍率 |
| `GENERAL` 及既有自定义类型 | 现有振动诊断指标，保持兼容 |

各项“相对基线倍率”定义为“当前值 / 对应基线值”；缺失或非正基线不匹配。触头磨损率使用插件已有的 0–1 原始比率值，不再除以基线。MCSA 间距定义为 `carrier_amp_db - sideband_amp_db`。所有设备类型均保留现有振动指标，另外增加本设备类别指标，以支持一台设备同时挂载振动和专用模态测点。全部观测值须有限，继续按现有比较运算符与优先级顺序首次命中。

演示默认规则对齐当前插件候选阈值：

- **电动机**：边频带/载波间距 `≤54 dB` 关注、`≤40 dB` 转子导条损伤疑似（高优先级）。54/40 dB 待离线与现场校准；`PDM_MCSA_ALERTS_ENABLED=false` 时仍不生成确定性 MCSA 告警。
- **断路器**：分闸时间倍率 `≥1.10` 关注；线圈峰值电流倍率 `≤0.80` 线圈驱动力不足。比率 `>1.20` 的危险/硬限因素仍由插件诊断优先。1.10/1.20/0.80 对齐现有插件默认配置。
- **调节阀**：死区倍率 `≥2.5` 关注、`≥5.0` 严重卡涩；泄漏 RMS `>0.2` 关注，`>0.5` 硬限击穿由插件诊断优先。阈值对齐现有默认配置。

## 默认规则与幂等

V4 的 `metric` CHECK 约束只允许振动指标，因此必须通过新迁移扩展允许值集合后，数据库才能保存多模态规则。V18 先提交扩展后的 `NOT VALID` 约束，让新规则可以写入；V19 再单独验证既有行，避免把全表验证扫描和 `ACCESS EXCLUSIVE` 锁放在同一迁移事务中。

应用启动时，只要三种多模态设备类别已经存在，规则初始化器就会为没有任何规则的类别补齐默认规则，不依赖 `PDM_DEMO_DATA`（该开关仍只控制演示资产种子）。若某类型已存在任何规则（包括禁用规则），初始化器保留该类型的全部现状，不再插入默认规则；管理员可通过现有规则页面创建、修改、停用规则。初始化使用 PostgreSQL advisory lock 防止多实例重复插入，且不会覆盖设备类型或点模态。

## 验收结果

- 新模态至少各有一条可配置规则，命中时其因素、依据、建议及规则版本出现在统一诊断/告警数据中。
- 硬限击穿仍用插件自带诊断，评分和告警门禁完全不变。
- UI 只为三种新设备类型显示各自适用指标；后端直接请求错误类别指标时返回 400。
- 缺失基线、缺失特征、零/负基线、NaN/Infinity 不会命中规则，也不会中断遥测评分。
- 默认阈值明确标为演示候选值，需现场校准。
