# 可配置基线学习时长

## 意图与范围

让部署者能配置基线采用的学习时间窗口。当前服务固定使用最近 300 个有效样本；模拟器标称约 1 Hz，但处理开销使实际采样率略低，因此 5 分钟窗口不足以稳定容纳 300 个有效样本。新增 `PDM_BASELINE_LEARNING_DURATION`，默认 `PT6M`。完成基线学习仍至少需要 300 个有效样本，且配置窗口内的 `freq_1x_amp` 与 `v_rms` 变异系数都须低于 0.25。

## 实现方案

- 采用用户选择的时间窗口方案：基线从配置时长内的有效样本计算，不再仅取固定的最近 300 个样本；同时保留 300 个样本的最低门槛。未达到时长覆盖、样本数或稳定性门槛时继续学习。
- 配置使用 Spring 可解析的 ISO-8601 `Duration`，环境变量默认 `PT6M`，为实际采样间隔大于 1 秒的模拟器留出余量。新配置同时用于首次学习和确认重置后的学习。
- 学习样本查询和清理按窗口截止时间执行，避免旧样本混入较新的学习窗口。窗口覆盖检查使用当前窗口内首末样本的时间跨度，并允许一个平均采样间隔的边界误差；改变时长后必须重新积累到覆盖新的窗口。
- 基线 API 返回当前配置时长；基线管理页展示学习窗口和“至少 300 个样本”的门槛，避免把样本数进度误认为时长已满足。
- CV 判定、P50 基线值、告警提示和锁定后不自动更新的行为保持不变。

## 考虑过的方案

- **按配置时长取样，并保留 300 样本最低门槛（选定）**：学习窗口跟随现场配置，同时不会因低采样率而用过少样本锁定。
- **只增加最短等待时间**：改动较小，但时长不会决定参与计算的样本窗口，因此不能直接表达用户希望配置的学习时长。
- **用时长乘固定采样频率换算样本数**：配置简单，但现场采样频率可能变化，容易偏离实际学习窗口。

## 验收标准

- 未设置环境变量时行为等价于默认 5 分钟窗口；设置如 `PT10M` 后，学习只使用最近 10 分钟有效样本。
- 少于 300 个样本或样本时间跨度不足配置时长时，基线保持 `LEARNING`。
- 窗口样本满足数量、时长和 CV 门槛后锁定 P50 基线；不满足 CV 时继续滚动学习。
- 基线页展示当前配置窗口；现有初始化与重置流程都使用同一配置。
